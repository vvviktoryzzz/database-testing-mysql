# Database Testing Checklist — MySQL

## Database Structure

* [ ] Проверить наличие таблицы `customers`
* [ ] Проверить наличие таблицы `products`
* [ ] Проверить наличие таблицы `orders`
* [ ] Проверить наличие таблицы `order_items`
* [ ] Проверить наличие Primary Key в каждой таблице
* [ ] Проверить наличие Foreign Key между связанными таблицами
* [ ] Проверить корректность связей между таблицами

## Customers

* [ ] Проверить получение всех клиентов
* [ ] Проверить фильтрацию клиентов по городу
* [ ] Проверить отсутствие клиентов с `NULL` в поле `email`
* [ ] Проверить уникальность значений `email`

## Products

* [ ] Проверить получение всех товаров
* [ ] Проверить поиск товаров по условию цены
* [ ] Проверить отсутствие `NULL` в поле `price`
* [ ] Проверить отсутствие нулевой или отрицательной цены
* [ ] Проверить товары без категории

## Orders

* [ ] Проверить получение всех заказов
* [ ] Проверить фильтрацию заказов по статусу
* [ ] Проверить отсутствие заказов без `customer_id`
* [ ] Проверить соответствие заказа существующему клиенту

## Order Items

* [ ] Проверить получение товаров, входящих в заказ
* [ ] Проверить соответствие `product_id` существующему товару
* [ ] Проверить соответствие `order_id` существующему заказу
* [ ] Проверить количество товаров в заказах

## JOIN

* [ ] Проверить `JOIN` между `orders` и `customers`
* [ ] Проверить `JOIN` между `order_items` и `products`
* [ ] Проверить корректность полученных связанных данных

## Aggregation

* [ ] Проверить количество заказов каждого клиента с помощью `COUNT`
* [ ] Проверить количество заказанных товаров с помощью `SUM`
* [ ] Проверить группировку данных с помощью `GROUP BY`
* [ ] Проверить фильтрацию групп с помощью `HAVING`

## Data Integrity

* [ ] Проверить отсутствие дубликатов email
* [ ] Проверить отсутствие `NULL` в обязательных полях
* [ ] Проверить корректность внешних связей
* [ ] Проверить корректность значений количества товаров
* [ ] Проверить корректность значений цены

## UNION

* [ ] Проверить объединение результатов двух запросов с помощью `UNION`

## Negative Testing

* [ ] Поиск клиентов без email
* [ ] Поиск товаров с некорректной ценой
* [ ] Поиск товаров без категории
* [ ] Поиск заказов без клиента
* [ ] Поиск дубликатов email
* [ ] Поиск записей с нарушением целостности связей
